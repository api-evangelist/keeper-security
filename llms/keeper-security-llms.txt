# Keeper Security

> Keeper Security is a zero-knowledge cybersecurity company providing an enterprise password manager, privileged access management (KeeperPAM), and Keeper Secrets Manager (KSM) for securing infrastructure secrets. Its developer surface is a multi-language SDK family plus the Keeper Commander and KSM command-line interfaces, rather than a public REST API.

## Products

- [Keeper Secrets Manager (KSM)](https://docs.keeper.io/en/keeperpam/secrets-manager): Cloud-based, zero-knowledge platform for securing infrastructure secrets (API keys, passwords, certificates) with client-side encryption and CI/CD injection.
- [Keeper Commander](https://docs.keeper.io/en/keeperpam/commander-cli): Python CLI and SDK for vault access, enterprise administration, and automated password rotation.
- [KeeperPAM](https://docs.keeper.io/en/keeperpam): Privileged access management including Connection Manager and KeeperDB.
